# Brickwave NextUI 00.2.0

- Application: Brickwave 0.4.25.
- Target: TrimUI Brick Pro, NextUI v6.14.0-compatible Tool Pak.
- Install path: `Tools/tg5040/Brickwave.pak`.
- Required runtime identity: `PLATFORM=tg5040`, `DEVICE=brickpro`,
  `IS_NEXT=yes`.
- NextUI host mode disables StockOS brightness, LED and stay-awake/stay-alive
  integration inside Brickwave.
- Session/settings and artwork are stored outside the Pak in `.userdata`.
- Existing StockOS packages and data are not included or modified.
- Physical NextUI device test: NOT_TESTED.
